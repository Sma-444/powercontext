## 三、提交前十分钟自检

```bash
# 1. 干净环境能跑
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m duban init            # 期望：7 篇 / 275 个片段
python -m duban ask "Raft 的 Figure 8 说明了什么问题？"

# 2. 测试与评测
python -m pytest                # 期望：9 passed
python -m duban eval            # 期望：Hit@3 ≈ 0.90，citation_valid = 1.0

# 3. 界面
python -m duban serve           # 打开 http://127.0.0.1:8765
```

### 用 CLI 完成站点发布（拿到 PAT 后一条命令）

```bash
export QODER_PERSONAL_ACCESS_TOKEN="<在 https://qoder.com/account/integrations 生成>"
qodercli sites operations                 # 看有哪些操作
qodercli sites describe publish_site      # 看参数（以实际输出为准）
qodercli sites publish_site --input '{"path": "site/", "name": "读伴 DuBan", "visibility": "public"}'
```

> 具体操作名与参数以 `qodercli sites describe <operation>` 的输出为准；
> 发布后在 `qodercli sites list` 里拿到公开地址，无痕窗口验一次。
