# Qoder Sites 发布指南

> 题面 2.3 要求：在 Qoder 里通过 **Sites** 创建并发布项目网站，可见范围设为「任何人都可访问」，
> 且网站要包含项目简介、解决的问题、核心功能、演示视频或截图、代码仓库链接、体验入口。

有两种做法，任选其一（推荐第 2 种，能直接用仓库里已经做好的站点）。

---

## 做法一：让 Qoder 从零生成站点（对话式）

1. 打开 Qoder，左侧栏点 **Sites** → **Add site**（会自动开一个新任务并引用 `@sites`）；
2. 选一个模板（简洁的 Landing Page / 产品介绍类），或者不选模板直接描述；
3. 把下面这段提示词粘进去（按实际情况改仓库地址与指标）：

```
做一个「读伴 DuBan」的项目官网，单页，中文，风格克制、偏学术：
- 顶部：产品名、一句话定位（会记住你的资料阅读助手）、两个按钮（看代码 / 怎么运行）
- 痛点区：找资料翻半天 / 记不住卡在哪 / 读一半忘了进度，三张卡片
- 核心功能：中文提问命中英文论文并给出页码引用、薄弱点记忆、复习清单，各配一段说明
- 架构：画一个数据流图，标明 seekdb（检索）与 PowerContext（记忆）分别在哪一环
- 数据：Hit@3 0.90、引用可回查 100%、21 道标注题、9 个测试通过
- 复现：三条命令的代码块
- 页脚：OceanBase 2026 · Qoder 赛题、代码仓库链接
素材截图我会在后面附上，请先用占位图，不要编造数字。
先生成预览，不要发布。
```

4. 生成后在右侧 **Sites** 面板预览，用 **Annotate** 或继续对话微调；
5. 上传截图（`records/screenshots/` 里的 png）；
6. 点 **Publish** → 选择 **任何人都可访问（public）** → 确认；
7. 复制完整访问地址（形如 `https://xxx.qoder.app`），用**无痕窗口**打开验证。

> 注意：Free 计划只支持静态站点（我们这个站就是静态的，够用）；
> 企业版账号无法设置公开访问，请用个人账号。

---

## 做法二：直接发布仓库里的 `site/`（推荐）

仓库里已经有做好的静态站（`site/index.html` + `site/style.css` + `site/assets/*.png`），
不依赖任何 CDN，直接上传即可。

### 用 CLI

```bash
# 安装并登录 Qoder CLI（见 https://docs.qoder.com/cli/installation）
qoder login

# 看看有哪些站点操作、每个操作要什么参数
qoder sites operations
qoder sites describe publish_site     # 参数以这条命令的输出为准

# 发布 site/ 目录（具体操作名与参数以 describe 的输出为准；
# 如果 CLI 版本不同，也可以在会话里说「把 site/ 目录发布成一个站点」，
# 内置的 sites:sites-building / sites:sites-hosting 技能会接手）
```

> CLI 的退出码：`0` 成功、`2` 入参非法、`3` 未登录、`4` 冲突、`5` 结果未知、`6` 取消。
> 遇到 `5` 先查询状态，不要直接重试。

### 用对话

在 Qoder 会话里说：

```
把 site/ 目录发布成一个静态站点，名称读伴 DuBan，描述「会记住你的资料阅读助手」，
可见范围设为任何人都可访问。发布前先告诉我它会怎么打包。
```

内置技能会先复述影响、等你确认，再执行发布。

## 发布后必做的四件事

| # | 做什么 | 为什么 |
| --- | --- | --- |
| 1 | 无痕窗口打开站点，确认未登录可访问 | 题面 3.1 第 1 条 |
| 2 | 检查站内链接：代码仓库、运行说明、演示截图 | 评审要从网站找到项目和复现方式 |
| 3 | 在站点「访问统计」里记下访问量/独立访客 | 使用效果材料 |
| 4 | 截图存进 `records/qoder/06-sites.png` | 提交材料要附证据 |

## 更新已发布的站点

改完内容要**再点一次「发布」**才会更新线上版本；只保存草稿不会生效。
评审结束前不要暂停或删除站点。

## 站点内容检查清单

- [ ] 一句话说清「解决谁的什么问题」
- [ ] 有截图或录屏（不是只有文字）
- [ ] 有架构图，标清 seekdb / PowerContext 的位置
- [ ] 有可复现的命令（安装 → 初始化 → 提问）
- [ ] 有代码仓库链接
- [ ] 有指标，且指标能在仓库里复跑出来（不要写跑不出来的数字）
- [ ] 页脚注明赛题与年份
